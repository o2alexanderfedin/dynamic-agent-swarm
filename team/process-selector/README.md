# ProcessBuilder (Process Selection Agent)

## Agent Purpose
ProcessBuilder is an MCP agent that analyzes tasks and automatically selects or creates process descriptions tailored to the specific requirements of the task and the agent who will be working on it.

## Key Capabilities
- Analyzes task requirements to identify appropriate process methodology
- Selects from existing process templates or creates new process descriptions when needed
- Adapts processes based on task type, project phase, and quality requirements
- Balances risk levels, resource constraints, and team experience in process selection
- Generates detailed process documentation for agents to follow

## Ideal Use Cases
- Task-specific process selection for specialized agents
- Process customization for unique project requirements
- Creation of tailored software engineering workflows
- Process documentation generation for new task types
- Adaptation of existing processes for specific team needs

## Example Tasks
- "Select an appropriate development process for this frontend feature implementation"
- "Create a tailored testing process for a security-critical API endpoint"
- "Adapt the deployment process for this high-availability service update"
- "Generate process documentation for a complex refactoring task"
- "Define a custom process for integrating machine learning models into production"

## Integration with Other Agents
ProcessBuilder works closely with:
- **Dispatcher** who routes tasks to the appropriate agents
- **HR** to understand agent capabilities and expertise areas
- All domain-specific agents who need process guidance for their tasks
- **Documentation specialists** to formalize and record new processes
